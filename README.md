# 🎯 Project Overview

This project implements a machine learning system that takes input text (for example, a tweet or short phrase) and predicts an appropriate emoji.

## Key Features
- Data preprocessing and analysis of a dataset of tweets + emojis
- Model training: LSTM and DistilBERT (or similar transformer) architectures
- Streamlit web application for a friendly user experience: type text → get emoji suggestions
- Focus on aesthetic UI/UX and clear model workflow
- Notebook‐based exploration (EDA, modelling) and full pipeline towards deployment

## 🚀 Setup Instructions

### Clone the repository
```bash
git clone https://github.com/kancharlasaisruthi/emoji-predictor.git
cd emoji-predictor
```

### Install dependencies
```bash
pip install -r requirements.txt
```

### Run the Streamlit application
```bash
streamlit run app/main.py
```

## 🧪 Usage
- Launch the Streamlit app (see above).
- Enter a short text (tweet, sentence) into the input box.
- The app will display one or more predicted emojis based on the trained model.
